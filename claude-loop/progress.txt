## Codebase Patterns
- Next.js 16 (no 15): `middleware.ts` -> `src/proxy.ts` (export `proxy`). Docs locales en `node_modules/next/dist/docs/`.
- `cacheComponents` desactivado: páginas que lean BD sin cookies()/headers() necesitan `await connection()` (next/server) o `export const dynamic = "force-dynamic"`, si no se prerenderizan en build.
- `LayoutProps`/`PageProps` son globales generados: `npm run typecheck` = `next typegen && tsc --noEmit`.
- Prisma 7: `prisma.config.ts` en la raíz (dotenv/config + env("DATABASE_URL")); usar `@prisma/adapter-pg`. `/src/generated/` ya está en .gitignore por si el generador escribe ahí.
- Tests Vitest en `tests/**/*.test.ts` (o `src/**/*.test.ts`); alias `@/` vía vite-tsconfig-paths.
- Tokens Tailwind: `bg-plato text-tinta text-tinta-suave azafran albahaca guindilla`, `font-display` (Bricolage) / `font-sans` (Atkinson).
- Prisma client: `import { db } from "@/lib/db"`; tipos/enums desde `@/generated/prisma/client`. Tras cambiar el schema: `npx prisma generate` (v7 `migrate dev` no genera ni siembra). SQL custom: `migrate dev --create-only` + editar + `migrate dev`.
- BD demo: `npm run db:seed` (idempotente). Usuarios: admin@mesaviva.co / admin123; laura@mesaviva.co y andres@mesaviva.co / mesero123. Mesas 1-4 "Salón principal" (Laura), 5-8 "Terraza" (Andrés).
- psql: `"/c/Program Files/PostgreSQL/18/bin/psql" "<DATABASE_URL sin ?schema=public>"` (psql rechaza el parámetro `schema`).
- Tests de integración: `tests/integration/*.test.ts` contra `TEST_DATABASE_URL` (BD restaurante_sistema_test, migrada sola por globalSetup); `npm test` requiere Postgres. Fixtures con sufijo aleatorio y limpieza en afterAll.
- Auth staff: proxy (`src/proxy.ts`) solo comprueba firma JWT; cada página/acción de staff llama `await requireStaff(role?)` de `@/lib/auth` (re-lee BD, ADMIN pasa todo). Helpers sin Prisma en `@/lib/session`; login/logout en `src/app/actions/staff.actions.ts`.
- Mutaciones de órdenes en `@/lib/domain/orders` no publican eventos: devuelven `{ orderId, tableId, tableNumber, waiterId, version, ... }` para publicar tras el commit. Errores tipados en `@/lib/domain/errors` (DomainError.code/message).
